# DriveFlow — Система автоматизации учета деятельности автошколы

Настольное клиент-серверное приложение для автоматизации работы сотрудников автошколы (ведение контингента курсантов, финансовый учет со скидками, планирование и контроль расписания практического вождения).

**Учебное заведение:** ОГБПОУ «Костромской политехнический колледж»  
**Специальность:** 09.02.07 «Информационные системы и программирование»  
**Дисциплина:** МДК.11.01 «Технология разработки и защиты баз данных»

## Стек технологий
* **Язык программирования:** Python 3.11+
* **Графический интерфейс (GUI):** CustomTkinter, Tkinter (ttk)
* **База данных:** MySQL (InnoDB, 10 нормализованных таблиц в 3НФ)
* **Драйвер БД:** `mysql-connector-python`

## Структура проекта
* `main.py` — точка входа в приложение, проверка соединения с сервером MySQL и инициализация структуры БД.
* `database.py` — слой доступа к данным (класс `Database`, DDL-запросы создания таблиц, CRUD-операции и бизнес-алгоритмы).
* `ui.py` — графический интерфейс пользователя (окно входа/регистрации, главное рабочее окно с вкладками и модальные диалоги).
* `requirements.txt` — список зависимостей проекта.

## Установка и запуск
1. Запустите сервер **MySQL** (например, через XAMPP) на порту `3306` и создайте пустую базу данных `autoschool_db` (кодировка `utf8mb4_general_ci`).
2. Установите необходимые зависимости из корня проекта:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   python main.py
   ```
